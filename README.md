# miku-md2formats-skills

An installable miku-soft Agent Skill for converting Markdown files to HTML
with optional embedded images, editable Word DOCX, practical Excel XLSX, and
editable PowerPoint PPTX files. It calls the corresponding local Node.js or
Java miku CLI artifacts and keeps conversion behavior with those upstream tools.

This repository contains the Agent Skill adapter; it does not create a new
`miku-md2formats` converter. `miku-md2html` is the upstream HTML tool, and
DOCX, XLSX, and PPTX are handled by their separate upstream CLI repositories.

## Included tools

| Markdown output | Node.js CLI | Java CLI |
| --- | --- | --- |
| HTML | `miku-md2html` 0.5.0 | `miku-md2html-java` 0.5.0 |
| Word DOCX | `miku-md2docx` 1.1.0 | `miku-md2docx-java` 1.1.0 |
| Excel XLSX | `miku-md2xlsx` 0.10.0 | `miku-md2xlsx-java` 0.10.0 |
| PowerPoint PPTX | `miku-md2pptx` 0.7.0 | `miku-md2pptx-java` 0.7.0 |

Java companions are available for all four output formats. For HTML, both
backends reference local raster images by default; use `--image-mode embed` to
include them in the HTML file. Remote images are rejected.

The installed skill is `igapyon-miku-md2formats`. It activates only when
explicitly named as `igapyon-miku-md2formats`, `miku-md2formats`,
`miku-md2formats-skills`, or one of the supported CLI names: `miku-md2html`,
`miku-md2html-java`, `miku-md2docx`, `miku-md2xlsx`, `miku-md2pptx`,
`miku-md2docx-java`, `miku-md2xlsx-java`, or `miku-md2pptx-java`.

## Install

Download the ZIP for a release and copy
`skills/igapyon-miku-md2formats/` from it into the Agent Skills home
directory. For Codex, that is normally `$CODEX_HOME/skills/`; if `CODEX_HOME`
is unset, use `~/.codex/skills/`. The resulting path should be
`<skill-home>/igapyon-miku-md2formats/SKILL.md`.

Use Node.js 22 or newer for the `.mjs` CLIs, or Java 8 or newer for the `.jar`
CLIs. The versioned runtime artifacts are self-contained; conversion does not
run `npm install` or call a network service.

## Repository layout

- `skills/igapyon-miku-md2formats/` is the canonical source for the installable
  skill, references, and four Node.js and four Java runtimes.
- `bundle/` is generated by `npm run build:bundle` and
  `npm run build:bundle:zip`; it is ignored by Git.
- `workplace/` is local-only scratch space. Only `.gitkeep` is tracked.
- `.codex/skills/` is reserved for local deployment copies and ignored.

## Development

Requires Node.js 22 or newer, Java 8 or newer, and the system `zip`/`unzip`
utilities for the full bundle verification workflow.

```sh
npm ci
npm test
npm run build
```

`npm run build` runs the tests, checks the bundled CLI versions, and creates
`bundle/igapyon-miku-md2formats-skills-0.3.6.zip`. GitHub Actions repeats the
build on Node.js 22 and 24 with Java 8 available. The release workflow attaches
the versioned ZIP to a published GitHub Release.

Upstream artifact versions, release links, source commits, and SHA-256
digests are recorded in
[`skills/igapyon-miku-md2formats/references/upstreams.md`](skills/igapyon-miku-md2formats/references/upstreams.md).
After an upstream release is selected, replace the corresponding runtime
artifact, update its pin and digest, then run `npm run build`.

See [`docs/development.md`](docs/development.md) for the initial scaffold and
reference decisions.
